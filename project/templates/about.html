RouteWise:Finding the Best Way to NED

Find the Most Efficient Gate to NED from Your Location

This project aims to find the most efficient routes for four team members traveling from different areas of Karachi — North Nazimabad, North Karachi, Gulshan-e-Iqbal, and Water Pump — to NED University, which has four entry gates. Each member starts from a unique location, and the objective is to determine which gate provides the shortest path for them.

Using a graph-based city model, we implement and compare four algorithms:

  • DFS (Depth-First Search)
  • BFS (Breadth-First Search)
  • Dijkstra’s Algorithm
  • A* (A-Star) Search

We evaluate each algorithm based on:

  • Path length
  • Execution time
  • Overall efficiency

Results include visual graphs, performance comparisons, and gate recommendations to ensure each member takes the most efficient route. This project blends real-world mapping with algorithmic problem-solving.
